❌ LOGS D'ERREUR - SIGNIFIANT UN PROBLÈME:
================================================================================

Si vous voyez une de ces erreurs:

❌ Erreur création table: [message]
  → La BD 'pharm' n'existe pas ou l'accès est refusé
  → Solution: Créez la BD manuellement ou vérifiez les droits

❌ Erreur lors du comptage: [message]
  → La requête SQL a échoué
  → Solution: Vérifiez que la table 'produits' est bien créée

❌ [X/25] Erreur: [message]
  → L'insertion a échoué pour ce produit
  → Solution: Exécutez AJOUTER_PRODUITS.sql manuellement

❌ ERREUR CRITIQUE lors de l'initialisation:
  → Problème grave de connexion ou de configuration
  → Solution: Vérifiez MyConnection.java (URL, user, password)

================================================================================
🔍 OÙ TROUVER LA CONSOLE DANS INTELLIJ:
================================================================================

1. Regardez en bas de la fenêtre IntelliJ
2. Vous verrez plusieurs onglets:
   - "Services"
   - "Run" (ou "Exécution")
   - "Debug"
   - "Console"
   - etc.

3. Cliquez sur l'onglet "Run" (ou "Exécution")
4. Les logs s'affichent dans ce panneau

Si vous ne voyez pas de logs:
   - Vérifiez que l'application est bien en cours d'exécution (indication verte)
   - Cliquez sur l'onglet "Run" pour basculer vers la console
   - Attendez quelques secondes après le démarrage

================================================================================
🎯 APRÈS LES LOGS - CE QUI SE PASSE ENSUITE:
================================================================================

1. APRÈS les logs (5-10 secondes), l'application JavaFX s'ouvre
2. Vous voyez: "Bienvenue sur PHARMAX"
3. Vous voyez 3 boutons:
   - "🛍️ Catalogue" (vert)
   - "🛒 Panier" (rouge)
   - "📜 Historique" (bleu)

4. Cliquez sur "🛍️ Catalogue"
5. ✅ RÉSULTAT: Les 25 produits s'affichent !

================================================================================
📱 SI L'INTERFACE NE MONTRE PAS DE PRODUITS:
================================================================================

Même si les logs disent "✅ 25/25 produits insérés":

1. VÉRIFIER: Vous avez bien cliqué sur "🛍️ Catalogue" ?
2. ATTENDRE: Parfois, ça prend quelques secondes à charger
3. RECHARGER: Essayez de cliquer plusieurs fois sur "Catalogue"
4. REDÉMARRER: Si ça ne marche pas, redémarrez l'app (Ctrl+C, puis F5)

Si toujours rien n'apparaît:
   → Les produits sont en BD mais ne s'affichent pas dans l'interface
   → Vérifiez CatalogueController.java pour un bug potentiel
   → Consultez GUIDE_AJOUT_PRODUITS.md

================================================================================
✅ VÉRIFICATION MANUELLE EN BASE DE DONNÉES:
================================================================================

Si vous voulez vérifier que les produits sont VRAIMENT en BD:

1. Ouvrez MySQL Workbench
2. Connectez-vous
3. Exécutez cette requête:

   USE pharm;
   SELECT COUNT(*) FROM produits;

4. Vous devez voir: "25"

5. Pour voir les produits:

   SELECT * FROM produits LIMIT 5;

6. Vous devez voir les 5 premiers produits avec leurs données
