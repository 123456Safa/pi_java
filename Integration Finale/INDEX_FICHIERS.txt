🎓 ARCHITECTURE TECHNIQUE SIMPLE:
================================================================================

Main.java
  │
  ├─> MyConnection.getInstance().getConnection()
  │   └─> Connexion à "jdbc:mysql://localhost:3306/pharm"
  │
  └─> DataInitializer.initializeSampleData()
      ├─> CREATE TABLE IF NOT EXISTS produits (...)
      ├─> SELECT COUNT(*) FROM produits
      └─> INSERT INTO produits (...) VALUES (...)  [25 fois]
          └─> Si 0 produit existant

CatalogueController
  └─> loadProduits()
      └─> ProduitService.select()
          └─> SELECT * FROM produits
              └─> Affiche 25 produits dans l'interface JavaFX
