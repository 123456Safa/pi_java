🆘 SI VOUS AVEZ UN PROBLÈME
================================================================================

□ Les logs ne montrent rien?
   → Vérifiez que vous regardez l'onglet "Run" en bas d'IntelliJ
   → Attendez 10 secondes après le lancement
   → Relancez l'application (F5)

□ Les logs affichent une erreur?
   → Consultez GUIDE_AJOUT_PRODUITS.md (section Dépannage)
   → Exécutez AJOUTER_PRODUITS.sql manuellement

□ Les produits ne s'affichent pas dans l'interface?
   → Vérifiez que vous avez cliqué sur "🛍️ Catalogue"
   → Attendez 5 secondes (le chargement peut être lent)
   → Relancez l'application complètement (Ctrl+C, puis F5)

□ Erreur "Connexion à la base de données refusée"?
   → Vérifiez que MySQL est en cours d'exécution
   → Vérifiez que la base 'pharm' existe
   → Consultez GUIDE_AJOUT_PRODUITS.md
