🎓 EXPLICATION TECHNIQUE:
================================================================================

QUAND L'APPLICATION DÉMARRE:
   1. Main.java s'exécute
   2. DataInitializer.initializeSampleData() est appelé
   3. DataInitializer fait les actions suivantes:
      a) Crée la table 'produits' si elle n'existe pas
      b) Compte les produits existants
      c) Si 0 produit → Insère 25 produits
      d) Affiche les logs dans la console

QUAND ON CLIQUE SUR "CATALOGUE":
   1. CatalogueController.loadProduits() s'exécute
   2. ProduitService.select() récupère tous les produits
   3. La requête SQL: SELECT * FROM produits
   4. Les produits sont affichés dans l'interface

POURQUOI ÇA FONCTIONNE:
   ✅ La table 'produits' est créée au démarrage
   ✅ Les 25 produits sont insérés automatiquement
   ✅ Le contrôleur récupère les produits
   ✅ L'interface les affiche

📞 SUPPORT / DÉPANNAGE:
================================================================================

PROBLÈME: "Aucun produit disponible"
   SOLUTION:
   1. Redémarrez l'application complètement
   2. Vérifiez les logs dans la console
   3. Exécutez AJOUTER_PRODUITS.sql manuellement
   4. Vérifiez avec VERIFIER_PRODUITS.sql

PROBLÈME: "Erreur de connexion à la base de données"
   SOLUTION:
   1. Vérifiez que MySQL est en cours d'exécution
   2. Vérifiez l'URL: jdbc:mysql://localhost:3306/pharm
   3. Vérifiez que l'utilisateur 'root' n'a pas de mot de passe
   4. Vérifiez que la base 'pharm' existe

PROBLÈME: "Erreur lors de l'insertion des produits"
   SOLUTION:
   1. Regardez le message d'erreur dans la console
   2. Exécutez VERIFIER_PRODUITS.sql
   3. Exécutez AJOUTER_PRODUITS.sql manuellement

PROBLÈME: "La console ne montre rien"
   SOLUTION:
   1. Cliquez sur l'onglet "Console" en bas d'IntelliJ
   2. Cherchez les logs "🔧 INITIALISATION"
   3. Si vous ne le voyez pas, le DataInitializer ne s'est pas exécuté
   4. Relancez l'application
